
# GarbageNet – AI-Powered Waste Classification App  

## Overview  
GarbageNet is a mobile application designed to promote **better waste management and recycling practices** using **AI-powered waste classification**. The app helps users properly dispose of trash by analyzing images and providing disposal instructions.  

## Features  
✅ **AI-Powered Waste Classification** – Users can upload an image, and the app will classify the waste type using a **quantized AI model (97% accuracy)**.  
✅ **Disposal Instructions** – Provides clear guidelines on how to recycle or dispose of different types of waste.  
✅ **Educational Resources** – Contains articles and interactive guides to raise awareness about sustainable waste management.  
✅ **Nearby Recycling Centers** – Helps users locate recycling facilities in their area.  
✅ **Complaint Submission** – Allows users to report improper waste disposal or request cleanup services.

## Installation & Setup ⚙️  
### Prerequisites  
- **Flutter SDK** installed ([Download Flutter](https://flutter.dev/docs/get-started/install))  
- **Python 3.8+** (for AI model development)  

### Running the App  
1. **Clone the repository:**  
   ```bash
   git clone https://github.com/your-username/GarbageNet.git
   cd GarbageNet
   ```
2. **Install dependencies:**  
   ```bash
   flutter pub get
   ```
3. **Run the app on an emulator or device:**  
   ```bash
   flutter run
   ```
